# Master Thesis – Adaptive Classification of Menopausal Symptoms

This repository contains the R code fies used for my master's thesis:

**"Entscheidungsorientierte adaptive Itemselektion zur Klassifikation menopausaler Symptomatik auf Basis der MRS-II"**

## Project Overview

The project investigates decision-oriented adaptive item selection for the classification of menopausal symptom severity based on the MRS-II. Performance is compared against fixed item selections.

## Repository Structure

| File | Description |
|--------|-------------|
| `01_prepareData.R` | Data preparation and preprocessing |
| `02_fitModels.R` | Estimation of classification models |
| `03_predAndPerf.R` | Adaptive predictions and performance evaluation |
| `03_predAndPerf_fixedSelections.R` | Evaluation of fixed item selections |
| `Abbildungen.R` | Generation of figures and plots |
| `DataManagement_Cimbolic.R` | Data management and dataset preparation |
| `Stichprobenbeschreibung.R` | Sample description and descriptive statistics |
| `dedaptiveExtended.R` | Implementation of the dedaptive testing framework |

## Software

Analyses were conducted in **R** using the **dedaptive** framework and related statistical packages.

The adaptive testing implementation is based on existing R scripts provided by the supervisor (Patric Wyss) of the master's thesis. These scripts served as the methodological foundation for the analyses and were adapted for the present study.
